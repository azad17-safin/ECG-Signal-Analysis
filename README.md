# Cognitive Rehabilitation App (Stroop Task)

A Python Tkinter desktop application designed to track cognitive performance, reaction times, and response accuracy using the classic **Stroop Effect** paradigm. Built for biomedical engineering and cognitive research applications.

---

## Key Features

- **Interactive GUI**: User-friendly desktop application built with `Tkinter`.
- **Patient Data Tracking**: Records Patient ID, Age, and Session Timestamps.
- **Stroop Cognitive Test**: Interactive color-word mismatch challenge to evaluate cognitive inhibition and speed.
- **Performance Metrics**: Measures total attempts, correct responses, and average reaction time in milliseconds (`ms`).
- **Data Export**: Automatically logs test results to a CSV file (`patient_cognitive_data_og.csv`) for longitudinal analysis.

---

## Tech Stack

- **GUI**: Python `tkinter`
- **Data Handling**: `csv`, `datetime`
- **Logic & Timing**: `random`, `time`
